Footprint 0.3.0 — Facebook navigation update

Installation/update:
1. Unzip this archive.
2. For an existing unpacked installation, replace the files in its existing folder with these files, then click Reload for Footprint at chrome://extensions. Keeping the same folder preserves the extension identity and local data.
3. For a new installation, enable Developer mode and Load unpacked; select the folder containing manifest.json.
4. Close old Facebook settings tabs and run a fresh scan from Footprint.

- Correct native radio labels, described options, and nested question/value rows.
- Phone/email checks now cover profile suggestions, with No one as the target.
- State-aware switches: repeated fixes do not invert the intended setting.

- Missing selected rows, unreadable lists, and failed verification cannot count as successful removals.
